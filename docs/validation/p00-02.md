# P00-02 — Identity, schema, authorization and local commit design

Disposition: **accepted by the project owner on 22 November 2026** for the
full Phase 0 identity/schema/authorization/local commit design. See the [owner decision record](../phase-00-progress.md#owner-decisions).

> Define stable identities, authorization order, schema rules and local commit semantics.
> Design review covers rename, DN collision, ACL inheritance, nested groups,
> concurrent updates and durable acknowledgment boundaries.

| Original criterion | Completed review material |
| --- | --- |
| Stable identities / rename | GUID and current domain-scoped SID/reference rules; same-domain preservation and explicit cross-domain SID exception |
| DN collision / schema | Structured/schema-governed names, local uniqueness/concurrency, class/syntax/system-field rules; no guessed SQL/Unicode matching |
| Authorization / inheritance | Ordered/object/attribute/control access, move source/destination rights, hidden-value filtering, protected descriptors and asynchronous propagation |
| Nested groups | Visited-set cycles, group scopes, GC incompleteness and token/PAC freshness distinguished from live membership |
| Concurrent updates | Current target-policy/security-version revalidation; local ACL revocation serialized with mutation, with explicit remote/inheritance/ticket freshness limits |
| Durable acknowledgment | Coupled local state/journal/audit/receipt durability, reauthorized retries, separate paged/background/cross-resource completion |
| Source / CI evidence | Nine worked cases bound to pinned ADTS/DRSR/DTYP sections; required integrity/negative checks preserve unrun outcomes |
