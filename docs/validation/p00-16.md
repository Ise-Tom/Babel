22 November 2026. The [registry](../../lab/specification-pins.json) records the
raw index digest and row IDs, listed programs and whether the rows show patent

Specification Promise inventory: 1035, 2136, 2782, 3244 and 3645. An ID match

The separate native CI archive packages the Babel LDAP/TLS lab binaries and

[Pages artifact verifier](../../scripts/verify_pages_artifact.py)

The packaging guard checks the archive's regular files against the existing
CI path scope, requires a reviewed purpose and exact bytes for fixture
locations, and rejects known publisher bytes, recognizable document formats,
opaque binary material outside the registered corpus, and unregistered assets.
It checks before creating output. Synthetic negative controls exercise an
unapproved path, a disguised document, a publisher digest match, a missing
registry entry, a purpose mismatch, changed bytes, and an external record
claiming distribution. These tests use project-owned bytes. Reviewers still
check provenance and the contents of plausible source text, including any
incorporated excerpts.

```sh
python scripts/package_source.py --tag v0.0.0-alpha.0 \
  --output /tmp/babel-source --audit-report /tmp/babel-source-rights.json
(cd /tmp/babel-source && sha256sum -c SHA256SUMS)
tar -tzf /tmp/babel-source/Babel-v0.0.0-alpha.0.tar.gz
python -m unittest discover -s tests -p test_delivery.py
```
